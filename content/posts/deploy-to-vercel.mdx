这篇文章记录把博客免费部署上线的完整步骤。

## 前置准备

- 一个 [GitHub](https://github.com) 账号
- 一个 [Vercel](https://vercel.com) 账号（直接用 GitHub 登录即可）

## 部署步骤

1. 把本项目推送到 GitHub 仓库：
   ```bash
   git init
   git add .
   git commit -m "init: blog"
   git remote add origin https://github.com/<你的用户名>/bokewen.git
   git push -u origin main
   ```
2. 打开 Vercel，点击 **Add New → Project**，导入刚才的仓库。
3. Vercel 会自动识别 Next.js，什么都不用改，直接点 **Deploy**。
4. 等待构建完成，就能通过 `xxx.vercel.app` 访问你的博客了。

## 之后怎么更新

只要往 `main` 分支推送代码，Vercel 就会自动重新构建并发布——写新文章也只是提交一个 `.mdx` 文件而已。

## 自定义域名（可选）

Vercel 支持绑定自己的域名。没有域名的话，用免费的 `vercel.app` 子域也完全够用；国内访问不稳定时再考虑买域名做解析。
